# Complex Enough 隱私權政策

**生效日期：** 2026 年 9 月 1 日<br>
**發布者：** Huan Min Wei<br>
**聯絡信箱：** support@complexenough.com

## 1. 適用範圍

本政策適用於 Complex Enough 的 skills-only 版本（穩定技術識別為 `orchestrate-multi-perspective-panel`），以及 `complexenough.com` 資訊網站；不涵蓋未來可能推出的 GUI、MCP server、託管應用程式、帳號系統或遙測服務。

## 2. Plugin 的資料行為

本 plugin 套件包含指令、schema 與確定性的本機驗證器。它不運作發布者控制的伺服器、不建立發布者帳號、不驗證使用者身分、不設定 cookie、不執行發布者分析，也不包含發布者遙測。

發布者不會透過本 skills-only 套件接收或保存 prompts、角色定義、會議產物、匯入的角色定位文字、repository 內容或驗證器輸出。提供給 ChatGPT、Codex 或其他相容 host 的資訊，由該 host 依使用者與 host provider 間的協議處理。

匯入的角色定位文字只在目前 host 工作流程中正規化。公開會議結果排除原始匯入 prompt、隱藏推理、私人草稿、原始內部訊息與 panelist transcripts。

## 3. 本機檔案

Repository scripts 可能讀取 skill source 與使用者指定的本機產物路徑，用於驗證或封裝檔案；它們只寫入明確指定的本機目標。Skills-only 版本不會將這些檔案傳送到發布者控制的服務。

## 4. 網站與支援資料

網站不使用發布者營運的分析工具、廣告追蹤器或 cookie。網站可能由 GitHub Pages 託管；GitHub 的基礎設施可能依其隱私條款處理一般請求資料，例如 IP 位址、瀏覽器資訊、請求網址與時間。

當你聯絡支援時，發布者會收到你選擇提供的電子郵件地址、訊息及附件。支援信件透過 Google Workspace 處理。請勿寄送密碼、API key、access token 或無關的個人資料。支援往來只在合理必要期間內保存，以處理及記錄請求；通常不超過 24 個月，但基於資安、濫用防止、爭議處理或法律要求時，可能保存更久。

## 5. 分享與出售

發布者不出售個人資料。支援資料只會在營運電子郵件或託管所必要的服務提供者、依你的指示，或法律要求及保護權利與安全所必要時揭露。

## 6. 你的選擇

你可寄信至 support@complexenough.com，要求查閱、更正或刪除發布者控制的支援紀錄內個人資料。發布者會依適用法律回應，並可能因資安或法律義務保留有限紀錄。

## 7. 兒童

Complex Enough 是供有權使用其 host product 的使用者使用之規劃與決策支援工具。發布者不會刻意透過 plugin 或網站蒐集兒童個人資料。

## 8. 政策變更

若未來版本新增會蒐集資料的 GUI、MCP server、遠端儲存、驗證、分析或其他由發布者控制的處理，本政策會在發布前更新。重大變更將以新的生效日期標示。
