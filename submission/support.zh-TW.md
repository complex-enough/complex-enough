**發布者：** Huan Min Wei<br>
**信箱：** support@complexenough.com

## 支援管道

- 一般錯誤、相容性回報、文件問題及功能建議，請使用公開的 [GitHub issue tracker](https://github.com/complex-enough/complex-enough/issues)。
- 隱私請求、疑似資料外洩，或公開回報會暴露敏感資訊時，請寄信至 [support@complexenough.com](mailto:support@complexenough.com)。
- 漏洞回報請遵循 `SECURITY.md`。請勿在公開 issue 貼出漏洞、秘密或私人資料。

## 支援範圍

Best-effort 支援涵蓋安裝與 plugin discovery、錯誤啟用或未啟用、角色提案及確認行為、公開 contract 驗證、確定性封裝，以及受支援版本中可重現的相容性缺陷。

支援不包含客製實作、未測試 host 的保證相容性、專業建議、第三方帳號或資料復原，以及完全由 host provider 控制的問題。

## 回覆預期

支援採 best-effort，沒有保證的首次回覆或解決時限。若提供最小重現步驟、精確版本、host、預期及實際行為，會較容易調查。

支援語言為英文與繁體中文。請勿寄送密碼、API key、access token 或無關的個人資料。
