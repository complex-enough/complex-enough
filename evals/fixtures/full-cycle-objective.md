# Full-cycle objective fixture

A multi-tenant field-service platform wants to reduce missed technician visits while adding customer self-service rescheduling.

Known constraints:

- Tenants configure working hours and travel buffers.
- Customers use Web links; technicians use a Mobile App with intermittent connectivity.
- The public API is used by two enterprise tenants.
- Billing charges a fee for late customer cancellations, but policy varies by tenant.
- Initial scope is product discovery through implementation readiness, not runtime implementation.

The user explicitly requests ideation, design, convergence, and a final readiness review. Preserve stage boundaries and reselect perspectives between stages.
